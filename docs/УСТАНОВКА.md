# Установка на Huawei Nova 15 Pro (EMUI 15)

## 1. Где взять APK

Каждый коммит в `main` собирается на GitHub Actions. Готовый APK публикуется в релизе **latest-debug**:

https://github.com/Da1tana/voice/releases/tag/latest-debug

- `voice-assistant-debug.apk` — само приложение;
- `SHA256.txt` — контрольная сумма для сверки.

Репозиторий приватный, поэтому скачивать нужно в браузере, где вы вошли в GitHub. Ещё вариант: скачать на компьютер и перекинуть файл на телефон по USB.

Это **debug-сборка**: она подписана отладочным ключом и разрешает HTTP-подключение к backend в локальной сети. Ключи и токены в APK не встроены — их вы вводите в настройках.

## 2. Подключение backend

Backend нужен, чтобы ассистент понимал команды. Без него работают только ручные экраны: задачи, заметки, расходы.

1. На компьютере или сервере:
   ```bash
   cd backend
   cp .env.example .env
   # впишите ANTHROPIC_API_KEY и придумайте APP_TOKEN:
   # python -c "import secrets; print(secrets.token_urlsafe(32))"
   docker compose up -d --build
   curl http://127.0.0.1:8000/health      # {"status":"ok",...}
   ```
2. Сделайте backend доступным с телефона, на выбор:
   - **Дома, по Wi-Fi.** Подходит для debug-сборки. В `docker-compose.yml` замените `"127.0.0.1:8000:8000"` на `"8000:8000"` и узнайте IP компьютера (`ipconfig` / `ip a`). Адрес для приложения: `http://192.168.x.x:8000`. Брандмауэр компьютера должен пропускать порт 8000.
   - **Откуда угодно.** VPS с доменом и Caddy (сертификат HTTPS получится автоматически) или туннель Cloudflare. Адрес: `https://assistant.ваш-домен.ru`.
3. В приложении: **Настройки → Сервер ассистента** → адрес и токен (значение `APP_TOKEN`) → «Сохранить» → «Проверить связь». Должно появиться «Сервер отвечает».

## 3. Установка APK

1. Скачайте `voice-assistant-debug.apk` и откройте его из «Файлов» или из загрузок браузера.
2. Если EMUI блокирует установку:
   - **Чистый режим** (Настройки → Система и обновления → Чистый режим): выключите его или разрешите установку этого файла, когда система предложит.
   - Разрешите установку из неизвестных источников приложению, через которое открываете APK (браузер или «Файлы»). Система сама покажет переключатель.
   - Если появится предупреждение о проверке приложения, выберите «Всё равно установить». Предупреждение возникает потому, что APK не из AppGallery.
3. При обновлении ставьте новый APK поверх старого — данные сохранятся, подпись у debug-сборок одна. Если система пишет о конфликте подписей, сначала сделайте экспорт (Настройки → Данные → Экспорт в JSON), затем удалите старую версию и установите новую.

## 4. Разрешения

При первом запуске приложение объясняет каждое разрешение. Все можно выдать позже в Настройках.

| Разрешение | Зачем | Если не выдать |
|---|---|---|
| Микрофон | голосовые команды, ключевая фраза | работает только текстовый ввод |
| Уведомления | напоминания, таймеры, значок «Ассистент слушает» | напоминания сохранятся, но не появятся |
| Точные будильники | напоминания минута в минуту | система может задержать напоминание на несколько минут |

Отдельно для EMUI: **Настройки → Аккумулятор → Запуск приложений → Ассистент → Управлять вручную** и включить все три переключателя (автозапуск, косвенный запуск, работа в фоне). Без этого EMUI закрывает приложение в фоне, и напоминания и ключевая фраза перестают работать.

## 5. Ограничения EMUI 15 и телефонов без сервисов Google

| Ограничение | Как проявляется | Что делать |
|---|---|---|
| Нет системного распознавателя речи (обычно его даёт приложение Google) | при нажатии на микрофон: «На телефоне нет сервиса распознавания речи» | писать команды текстом («Написать текстом» на главном экране); установить приложение со службой распознавания и выбрать его в Настройках → Система → Язык и ввод → Голосовой ввод; постоянное решение — офлайн-распознавание Vosk (в планах) |
| Нет русского голоса синтеза речи | ответ показывается текстом, но не звучит | установить движок с русским голосом (например, RHVoice) и выбрать его в настройках «Синтез речи»; затем Настройки ассистента → Прослушать |
| Агрессивное энергосбережение | ключевая фраза перестаёт работать, напоминания опаздывают | ручное управление запуском (раздел 4) |
| Android запрещает включать микрофон из фона | после перезагрузки телефона ключевая фраза не включится сама | один раз открыть приложение; напоминания восстанавливаются сами |
| Распознаватель может не работать, когда приложение свёрнуто | после ключевой фразы ничего не происходит | открыть приложение или пользоваться кнопкой |
| Ключевая фраза требует Picovoice | без ключа переключатель выключается с ошибкой | получить AccessKey в Picovoice Console, для фразы «Ассистент» добавить файлы в `assets/wakeword/` (см. README) |

## 6. Типовые ошибки

| Сообщение или симптом | Причина | Решение |
|---|---|---|
| «Укажите адрес сервера ассистента в настройках» | адрес backend пустой | Настройки → Сервер ассистента |
| «Нет подключения к серверу ассистента» | backend не запущен, неверный адрес, телефон в другой сети, брандмауэр | открыть `адрес/health` в браузере телефона; проверить `docker compose ps` |
| «Проверить связь» не проходит для `http://…` в release-сборке | release-сборка разрешает только HTTPS | использовать debug-APK или настроить HTTPS |
| «Сервер отклонил токен приложения» | токен в приложении не совпадает с `APP_TOKEN` | вписать тот же токен, «Сохранить» |
| «Сервер ассистента недоступен (код 502)» | backend не может достучаться до Anthropic или ключ неверный | `docker compose logs`; проверить `ANTHROPIC_API_KEY` и баланс в Claude Console |
| «Слишком много запросов» | лимит Anthropic | подождать минуту |
| «Сервер ассистента не ответил вовремя» | медленная сеть или модель | повторить команду |
| «Диалог устарел. Повторите команду» | backend перезапускался или прошло больше 30 минут | повторить команду: новый диалог начнётся сам |
| «Не расслышал. Повторите, пожалуйста» | распознаватель ничего не услышал | говорить сразу после нажатия, ближе к телефону |
| Напоминание пришло с опозданием | нет разрешения на точные будильники или энергосбережение EMUI | выдать «Точные будильники», ручное управление запуском |
| Не устанавливается APK | Чистый режим или запрет неизвестных источников | раздел 3 |
| Импорт: «Файл не похож на резервную копию ассистента» | выбран не тот файл | выбрать JSON, созданный кнопкой «Экспорт в JSON» |
