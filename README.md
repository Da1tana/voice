# Голосовой Ассистент

Нативное Android-приложение (Kotlin + Jetpack Compose) и минимальный backend на FastAPI, который связывает телефон с Claude.

## 1. Что это за приложение

Личный голосовой помощник для Android 10+ (в том числе Huawei на EMUI без сервисов Google). Вы нажимаете кнопку микрофона или говорите ключевую фразу, телефон распознаёт речь, отправляет **только текст** на ваш сервер, Claude решает, что сделать, а телефон выполняет действие у себя и озвучивает ответ.

Что умеет первая версия:

- задачи со сроками, фильтры «сегодня / завтра / все / выполненные»;
- заметки с тегами и поиском;
- расходы с итогами за день, неделю, месяц и разбивкой по категориям;
- напоминания (точные будильники) и таймеры;
- история голосовых запросов;
- экспорт и импорт всех данных в JSON, полное удаление;
- ключевая фраза через Porcupine — по желанию, приложение полностью работает и по кнопке.

Все данные хранятся только на телефоне (Room). Ключ Anthropic хранится только на сервере.

## 2. Архитектура и схема работы

```
┌──────────────── Телефон ────────────────┐         ┌──── Ваш сервер ────┐        ┌─────────┐
│ Porcupine (wake word, офлайн)            │         │ FastAPI             │        │         │
│        │                                 │  HTTPS  │  /assistant         │  HTTPS │ Claude  │
│ SpeechRecognizer → текст ────────────────┼────────►│  /assistant/result  ├───────►│ Messages│
│                                          │         │  системный промпт   │        │   API   │
│ ToolExecutor ◄── tool_call ──────────────┼─────────┤  описания tools     │◄───────┤         │
│   UseCase → Room                         │         │  контекст диалога   │        │         │
│ результат ───────────────────────────────┼────────►│  (в памяти, TTL)    │        └─────────┘
│ TextToSpeech ◄── финальный ответ ────────┼─────────┤                     │
└──────────────────────────────────────────┘         └─────────────────────┘
```

Поток одной команды:

1. `POST /assistant` с текстом, локалью, часовым поясом и текущим временем.
2. Backend зовёт Claude с системным промптом и 10 инструментами.
3. Если Claude хочет действие, backend возвращает `tool_call`, телефон выполняет его локально и шлёт `POST /assistant/result`.
4. Шаги 2–3 могут повториться (например, `list_tasks` → `complete_task`), не больше 4 раз за команду.
5. Финальный `reply` показывается на экране и озвучивается.

### Android (`android/`)

Чистая архитектура MVVM + Repository, Hilt для DI.

| Пакет | Что внутри |
|---|---|
| `ui` | Compose-экраны, навигация, ViewModel'и |
| `ui.theme` | Material 3, светлая и тёмная тема |
| `data.local` | Room: сущности, DAO, база |
| `data.remote` | Retrofit API, DTO, ошибки backend |
| `data.repository` | репозитории, DataStore-настройки, экспорт/импорт |
| `domain.model` | доменные модели |
| `domain.usecase` | по UseCase на каждый инструмент, `ToolExecutor`, `ProcessVoiceCommandUseCase` |
| `service` | foreground service, распознавание речи, TTS, будильники, уведомления |
| `di` | Hilt-модули |
| `util` | даты, форматирование, валидация, логирование без личных данных |

Модуль `:wakeword` изолирует Porcupine: приложение зависит только от интерфейса `WakeWordDetector`.

Даты в базе — UTC epoch milliseconds, отображение — в зоне устройства. Суммы расходов хранятся в копейках (поле `amount`), чтобы не терять точность.

### Backend (`backend/`)

`main.py` (эндпоинты, авторизация, CORS, SSE), `claude_service.py` (Messages API, контекст диалогов), `tools.py` (системный промпт и схемы инструментов), `models.py`, `config.py`. Подробнее — в `backend/README.md`.

## 3. Как запустить backend

```bash
cd backend
cp .env.example .env          # впишите ANTHROPIC_API_KEY и APP_TOKEN
docker compose up -d --build
curl http://127.0.0.1:8000/health
```

Без Docker:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Release-сборка приложения ходит **только по HTTPS**. Варианты:

- VPS + Caddy (сам получит сертификат Let's Encrypt): `assistant.example.ru { reverse_proxy 127.0.0.1:8000 }`;
- туннель (Cloudflare Tunnel и аналоги) к домашнему компьютеру.

Для отладки debug-сборка разрешает HTTP — можно указать `http://192.168.1.10:8000`.

Тесты backend: `pip install -r requirements-dev.txt && pytest -q` (реальные запросы к Anthropic не отправляются).

## 4. Как получить и безопасно задать ANTHROPIC_API_KEY

1. Зайдите в [Claude Console](https://console.anthropic.com), раздел API Keys, создайте ключ.
2. Положите его **только** в `backend/.env` (`ANTHROPIC_API_KEY=...`) или в секреты вашей платформы. Файл `.env` уже в `.gitignore`.
3. Никогда не вставляйте ключ в приложение: APK легко распаковать.
4. Сгенерируйте отдельный `APP_TOKEN` — он защищает ваш backend от чужих запросов:
   `python -c "import secrets; print(secrets.token_urlsafe(32))"`
   Этот токен впишите в настройках приложения. Если его украдут, просто смените — ключ Anthropic не пострадает.
5. В консоли Anthropic поставьте лимит расходов на ключ.

Модель задаётся переменной `CLAUDE_MODEL` (по умолчанию `claude-sonnet-5-5`).

## 5. Как собрать Android-приложение

Нужно: Android Studio (актуальная), JDK 17, Android SDK 35.

```bash
cd android
./gradlew assembleDebug                 # APK: app/build/outputs/apk/debug/
./gradlew testDebugUnitTest             # unit-тесты UseCase и разбора ответов backend
./gradlew installDebug                  # установка на подключённый телефон
```

Либо откройте папку `android/` в Android Studio и нажмите Run.

На Huawei: включите «Режим разработчика» (7 раз нажать на номер сборки) → «Отладка по USB».

### Ключевая фраза (необязательно)

1. Зарегистрируйтесь в [Picovoice Console](https://console.picovoice.ai), скопируйте AccessKey.
2. Для русской фразы «Ассистент»: в разделе Porcupine создайте фразу, язык Russian, платформа Android, скачайте `.ppn`. Переименуйте в `assistant_ru.ppn`.
3. Скачайте русскую модель `porcupine_params_ru.pv` из репозитория Porcupine (`lib/common`).
4. Положите оба файла в `android/app/src/main/assets/wakeword/` и пересоберите.
5. В приложении: Настройки → Ключевая фраза → вставьте AccessKey → включите переключатель.

Без своих файлов можно сразу выбрать встроенные английские фразы (Jarvis, Computer, Porcupine).

## 6. Какие разрешения нужны и зачем

| Разрешение | Зачем |
|---|---|
| `RECORD_AUDIO` | слышать команды и ключевую фразу |
| `POST_NOTIFICATIONS` | напоминания, таймеры, уведомление «Ассистент слушает» |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MICROPHONE` | слушать ключевую фразу, когда приложение свёрнуто |
| `SCHEDULE_EXACT_ALARM` | напоминания минута в минуту |
| `RECEIVE_BOOT_COMPLETED` | восстановить напоминания после перезагрузки |
| `INTERNET`, `ACCESS_NETWORK_STATE` | связь с backend |
| `WAKE_LOCK` | нужен WorkManager для восстановления напоминаний |

При первом запуске приложение показывает экран с объяснением каждого разрешения. Повторно — в Настройках.

Ограничения Android, о которых стоит знать:

- Сервис с микрофоном нельзя запустить из фона или после перезагрузки (Android 14+). Поэтому прослушивание ключевой фразы включается при открытии приложения, а после перезагрузки телефона нужно один раз открыть приложение.
- Системный распознаватель речи (обычно приложение Google) может отказаться работать, когда наше приложение свёрнуто. Тогда после ключевой фразы откройте приложение — или пользуйтесь кнопкой.

### Особенности Huawei

- **Энергосбережение.** Настройки → Аккумулятор → Запуск приложений → «Ассистент» → «Управлять вручную», включить все три переключателя. Иначе EMUI закроет сервис и будильники.
- **Распознавание речи.** Без сервисов Google на телефоне может не быть системного распознавателя. Приложение проверит это само: на Android 12+ попробует распознавание на устройстве, иначе покажет предупреждение в настройках. Команды всегда можно писать текстом на главном экране. Постоянное решение — офлайн-распознавание Vosk (см. дорожную карту).
- **Синтез речи.** Если русского голоса нет, ответ показывается текстом. Установите движок TTS с русским голосом (например, RHVoice) и выберите его в системных настройках «Синтез речи».

## 7. Как настроить backend URL в приложении

Настройки → «Сервер ассистента»:

1. Адрес, например `https://assistant.example.ru` (без `/assistant` на конце).
2. Токен приложения — значение `APP_TOKEN` из `.env`.
3. «Сохранить», затем «Проверить связь» — приложение вызовет `/health`.

Для эмулятора Android локальный компьютер доступен как `http://10.0.2.2:8000`.

## 8. Какие голосовые команды поддерживаются

| Скажите | Действие |
|---|---|
| «Добавь задачу купить хлеб завтра в шесть вечера» | `add_task` |
| «Что у меня на сегодня?» / «Какие задачи на завтра?» | `list_tasks` |
| «Отметь задачу про хлеб выполненной» | `list_tasks` → `complete_task` |
| «Напомни через час позвонить маме» | `set_reminder` |
| «Запиши: код от домофона 1234, тег дом» | `add_note` |
| «Где я записывал код домофона?» | `search_notes` |
| «Потратил 350 рублей на кофе» | `add_expense` |
| «Сколько я потратил за неделю?» | `get_expense_summary` |
| «Поставь таймер на 10 минут» | `start_timer` |
| «Как мой день?» / «Подведи итоги дня» | `get_today_summary` |

Обычные вопросы («сколько будет 15% от 2400») Claude отвечает без инструментов. Относительные даты («завтра», «через час», «вечером») модель переводит в точное время по часовому поясу телефона.

Удалять задачи, заметки и расходы голосом нельзя намеренно — только на экране, с подтверждением.

## 9. Дорожная карта

- **Whisper / Vosk** — офлайн-распознавание русской речи на телефоне, без зависимости от Google. Vosk — лёгкий вариант для Huawei; Whisper (whisper.cpp) — точнее, но тяжелее.
- **ElevenLabs** — естественный голос: синтез на backend, телефон получает аудио. Ключ ElevenLabs тоже хранится только на сервере.
- **Календарь** — чтение и создание событий через CalendarProvider.
- **Виджет** на рабочий стол с кнопкой микрофона и задачами на сегодня (Glance).
- **Офлайн-режим** — очередь команд без сети и простые команды («добавь задачу…») без обращения к серверу.
- Потоковый ответ в приложении: backend уже отдаёт SSE (`/assistant/stream`), клиенту осталось начать озвучку по первым предложениям.
- Хранение контекста диалогов в Redis для нескольких экземпляров backend.
